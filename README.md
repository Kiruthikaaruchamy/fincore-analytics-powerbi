# FINCORE ANALYTICS
### Financial Transaction Analysis & Business Intelligence Dashboard

## Project Overview

FINCORE ANALYTICS is an interactive financial transaction analytics solution developed using Microsoft Power BI. The project focuses on analyzing financial performance, transaction patterns, customer demographics, and regional business contributions through interactive visualizations and key performance indicators.

The dashboard enables stakeholders to monitor financial operations, evaluate transaction performance, identify business trends, and derive actionable insights to support data-driven decision-making.

## Business Objectives

- Monitor overall financial performance and transaction growth.
- Analyze monthly transaction trends and patterns.
- Evaluate successful, failed, and pending transactions.
- Identify high-performing customer segments.
- Compare financial performance across states.
- Analyze transaction types, fees, and tax contributions.
- Understand customer demographics.
- Track Year-over-Year (YoY) performance.

## Dashboard Features

### 1. Overview Analysis
- Total Amount
- Total Transactions
- Total Tax
- Average Transaction Value
- Total Fees
- Monthly transaction trends
- Transaction status distribution
- Customer segment analysis
- State-wise financial performance
- Transaction type analysis
- Gender-based transaction analysis

### 2. Transaction Details
- Detailed transaction-level records.
- Transaction ID and customer information.
- Transaction status and type.
- Customer segment and demographic details.
- Financial amount, fees, and tax.
- Interactive drill-through navigation.

## Interactive Capabilities

- Year-based filtering.
- Dynamic metric selection.
- Occupation-based filtering.
- Category-based filtering.
- Interactive visual cross-filtering.
- Drill-through to detailed transaction records.
